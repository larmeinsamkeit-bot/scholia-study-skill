Expected valueWrong · you were certain

A fair die is rolled once. Let X be the number shown. What is E[X]?

You said3
Answer3.5

An expected value is a weighted average, not a middle outcome. Add each value times its probability: (1+2+…+6)/6 = 3.5. It's fine — normal, even — for E[X] to be a value X can never land on.

PMF validityWrong · fairly sure

Which of these can be a PMF on {1, 2, 3}?

You chose p = (0.5, 0.4, 0.2). It sums to 1.1 — always add them up before anything else.

Discrete vs continuousRight · but guessing

Is “the number of emails you get tomorrow” discrete?

Yes — you can list its values 0, 1, 2, … even though the list never ends.

Capital X vs small xlinked to 1 of your mistakes

Why it trips people: both letters appear in the same line, P(X = x), and look alike in handwriting.

The fix: read X as “the random quantity” and x as “a particular number it might equal”. P(X = 4) asks: how likely is the variable to come out as 4?

X = sum of two dice
P(X = 4) = P{(1,3),(2,2),(3,1)} = 3/36
