Discrete random variables

Turning the outcomes of an experiment into numbers you can add, average and plot.

After this you can

1. From outcomes to numbers

A random variable is a rule that assigns a number to every outcome in the sample space. Roll two dice: the outcome is a pair like (2, 5), but we often care only about the sum, 7. The sum is the random variable X.

It is discrete when its possible values can be listed — 2, 3, …, 12 here — even if the list is infinite, like the number of coin flips until the first head.

2. The PMF

The probability mass function gives each value its probability: p(x) = P(X = x). Two checks every PMF must pass: no value is negative, and they add up to exactly 1.

Key terms

Random variable
A function from outcomes to real numbers.
PMF
p(x) = P(X = x) for each possible value x.
Expected value
The probability-weighted average, Σ x·p(x).
