# STAT 110 · Homework 3 and the instructor's answer key

## Problem 1
A fair coin is tossed 3 times. What is the probability of getting exactly 2 heads?

**Key:** 3/8

## Problem 2
X takes the values 1, 2, 3 with probabilities 0.2, 0.5, 0.3. Find E[X].

**Key:** E[X] = 1(0.2) + 2(0.5) + 3(0.3) = 2.2

## Problem 3
Using the X from Problem 2, find Var(X).

**Key:** E[X²] = 1(0.2) + 4(0.5) + 9(0.3) = 4.9, so Var(X) = 4.9 − 2.2 = 2.7

## Problem 4
A test for a disease has sensitivity 0.9 and specificity 0.95. The disease prevalence is 0.02.
Given a positive test, what is the probability the person has the disease?

**Key:** 0.9 × 0.02 / (0.9 × 0.02 + 0.05 × 0.98) ≈ 0.269
